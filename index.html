Instructor guide — these discussion questions are not shown to students. Use them to facilitate classroom conversation after students have explored each scenario in the simulator.
Alice Chen
Think about it
Q: If someone already has Alice's password from the hotel breach, what single thing would stop them accessing the production database?
Q: Why does Alice's Level 4 access make this situation especially dangerous compared to if the same thing happened to Dave the intern?
Simulator: Set user to Alice, resource to Production DB, network to Remote, risk to Impossible Travel. What happens? Now turn MFA off — does the decision change?
Bob Martinez
Think about it
Q: Why can't a human be responsible for 847 login attempts in 4 minutes? What does this tell you about who — or what — is attacking Bob's account?
Q: Bob has MFA set up, but there's still a weakness in his setup. What is it, and how could an attacker exploit it?
Simulator: Set Bob on a BYOD device accessing the HR Records system after hours. What decision does the policy engine make, and why?
Carol Singh
Think about it
Q: Carol accessed the wiki without VPN using an expired token. In a zero trust system, why should every request be re-verified — not just the first login?
Q: What is the difference between Carol's SMS-based MFA and using an authenticator app or hardware key? Which would protect her better against the phishing attack she experienced?
Simulator: Test Carol accessing the code repository from a Remote / untrusted network with MFA on. Does she get access? Now switch to a managed device on VPN — how does the decision change?
Dave Kim
Think about it
Q: Dave says he was "just exploring." Does intent change whether a security system should block his access? Why or why not?
Q: The organisation left old credentials on a wiki page. Is this Dave's fault, the company's fault, or both? What should have prevented this?
Simulator: Set Dave as the user, Production DB as the resource, risk to Privilege escalation. What happens? Ask students: can any combination of context settings grant Dave access to the Production DB? Why not?
TechVendor Support
Think about it
Q: Why is a shared account so dangerous from a security perspective? What should TechCorp have required from the vendor instead?
Q: The security team was not involved in approving the vendor contract. Why does a third-party vendor's security matter to TechCorp's own security?
Simulator: Set External User on TOR network, accessing the Internal Wiki — the lowest-clearance resource. Does zero trust grant access? Ask students: why does network origin block access even for a public-facing resource?
